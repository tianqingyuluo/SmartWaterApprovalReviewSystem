# 前端页面说明

## CP2 AI 知识库与 MCP 演示台

路径：`/mcp-demo`

用途：为 CP2 验收提供独立演示台，展示知识库状态、MCP 服务状态、工具调用结果和接口契约样例。

### 页面能力

- 状态面板：展示知识包版本、MCP 服务状态、最近一次调用工具、结果来源。
- `knowledge_search` 调用区：支持输入查询词和 `topK`，展示结果片段、来源分区、材料类型、字段路径、`basisRefs` 和 `sourceIds`。
- `check_completeness` 调用区：支持勾选三类 MVP 材料，展示完整性判断、缺失材料和结构化问题提示。
- JSON 契约侧栏：展示最近一次请求和响应，同时提供两个工具的请求/响应字段说明。
- 状态处理：加载中、空结果、失败、实时服务和演示兜底来源均有可见提示。

### 交互边界

- 页面不依赖 CP3 审批待办、任务状态或结果回写链路。
- 页面不会产生审批通过、退回或人工复核动作。
- 页面只展示工具演示结果，固定提示“演示模式 / 非正式审批结论”。

### 数据来源

- 首选：`POST /mcp/tools/knowledge_search` 与 `POST /mcp/tools/check_completeness`。
- 兜底：`frontend/src/api/mcpDemo.ts` 中的本地演示数据。
- 兜底触发后，状态面板会显示“演示兜底”，避免误认为真实 MCP 服务在线。
